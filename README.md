# ✨ IQ MARTINS
### Premium Gold Edition | Roblox Script Hub

**IQ Martins** é um Script Hub desenvolvido por **Martins**, com foco em automação, desempenho, praticidade e uma interface moderna para PC e dispositivos móveis.

O projeto apresenta um visual premium em preto e dourado, efeitos de brilho animados e diversas funcionalidades organizadas para proporcionar uma experiência simples e personalizada.

## 🚀 Como executar

Utilize um ambiente Lua compatível com as funções necessárias ao script.

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/thiaguinhoqwf/IQ-Martins/main/IQ_Martins.lua"))()
```

Ao iniciar:

1. Selecione seu idioma.
2. Acesse a tela de Key.
3. Insira sua chave de acesso.
4. Abra o painel IQ Martins.
5. Ative as funcionalidades desejadas.

## 🔐 Proteção do código

O IQ Martins utiliza um sistema de distribuição com:

- Duas etapas de ofuscação.
- Compactação e codificação do código.
- Verificação de integridade.
- Identificação de autoria.

A ofuscação dificulta a leitura e a reprodução não autorizada, mas não garante proteção absoluta contra engenharia reversa.
